# Non-Production Legacy QA Run

This folder is a framework smoke-test artifact. It is not a production meeting
record and should not be rehydrated wholesale into agent context.

Use it only to inspect local ASR API behavior and high-level reports. Full
transcripts and evidence JSON remain generated artifacts; production flows keep
only pointers, hashes, bounded previews, topic maps, QA gates, and open
questions in the main context.
