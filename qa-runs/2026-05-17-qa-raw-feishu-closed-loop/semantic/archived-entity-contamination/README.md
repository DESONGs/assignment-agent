# Archived Entity-Contaminated Output

This directory keeps the previously published third meeting note that passed
format cleanup but still contained cross-meeting semantic contamination, such as
expanding a vague "表" reference into "HR 表" and strengthening a conditional
development timing into a firm commitment.

The corrected publishable document is in the parent `semantic/` directory and
was generated with `meetingProfile`, `siblingForbiddenTerms`, and semantic gate
checks.
